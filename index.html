Student Depression: a beginner machine learning project

Predicting depression from student survey data with logistic regression, and working out why the model predicts what it does.

Open the notebook in Colab View the code on GitHub
Please note: this is a learning project using self-reported survey data. It is not a clinical tool and must never be used to diagnose or judge a real person. If you or someone you know is struggling, please speak to a doctor or a mental health professional.

About the project

I built this to learn the full machine learning workflow from scratch: cleaning data, exploring it, training models, evaluating them honestly, and interpreting the results. The goal was understanding, not squeezing out the highest possible score.

The data

Each row is one student, with columns such as age, gender, academic pressure, financial stress, sleep duration, dietary habits, study hours, family history and a question about suicidal thoughts. The target is Depression (1 = yes, 0 = no), so this is a classification problem.

The classes are fairly balanced, so a lazy model that always guesses “depressed” would already be right about 58.5% of the time. That is the baseline any real model has to beat.

Preparing the data

  • Dropped columns with no useful information: id, Profession (almost everyone is “Student”), Work Pressure and Job Satisfaction (almost always 0).
  • Left out City and Degree (many categories) to keep the first model simple.
  • Removed a handful of rows with missing values, vague “Others” categories, or impossible zeros.
  • One-hot encoded text columns and standardised numeric columns, all inside a scikit-learn Pipeline so nothing from the test set leaks into training.
  • Split the data 80% / 20% into training and test sets, stratified by the target.

What the data shows

Looking at the share of students with depression in each group (approximate figures from the full dataset):

  • Academic pressure: rises from about 19% at the lowest level to about 86% at the highest.
  • Financial stress: rises from about 32% to about 81%.
  • Age: younger students show higher rates (about 71% for ages 18–21 versus about 41% for over 30).
  • Gender: almost no difference.
  • CGPA: only a weak relationship.

Models and results

I compared a do-nothing baseline, logistic regression and a random forest. The simple logistic regression did about as well as the random forest, so I kept it because it is far easier to explain.

Five-fold cross-validation gave an accuracy of about 85%, so the result is not just a lucky split.

What the model learned

Reading the logistic regression coefficients (on standardised features), the factors that most raised the predicted risk were:

  1. Having had suicidal thoughts (by far the largest effect)
  2. Academic pressure
  3. Unhealthy dietary habits
  4. Financial stress
  5. Longer work or study hours and sleeping under five hours

Older age and higher study satisfaction lowered the predicted risk. Gender and CGPA made almost no difference.

An important experiment

The suicidal-thoughts column dominates the model, and it is arguably very close to the outcome itself rather than an independent risk factor. So I re-ran the model without it:

AccuracyRecallROC-AUC
With suicidal thoughts84.4%87.9%0.92
Without suicidal thoughts79.8%84.9%0.87

The model still works from lifestyle and pressure factors alone, just less well. Which version is “right” depends on the question you are asking.

Limitations

  • Association is not causation. The model shows what goes with depression in this data, not what causes it.
  • Self-reported survey data, not clinical diagnoses.
  • Mixed sample: ages go up to 59 and many respondents are school-level students, so the results may not generalise.
  • Little is known here about how the data was collected, which limits any real-world conclusions.

What I learned

  • Always compare against a baseline.
  • Split first and keep preparation inside a pipeline to avoid data leakage.
  • Look beyond accuracy: confusion matrix, recall, precision and ROC-AUC.
  • A simple, explainable model is often good enough.
